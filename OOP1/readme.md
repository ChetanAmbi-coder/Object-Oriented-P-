# Java Object-Oriented Programming (OOP) – Part 1

## 📌 Overview

This repository contains my initial learning of **Object-Oriented Programming (OOP) in Java**. I am learning the fundamental concepts of Java, including classes, objects, constructors, and object handling.

The purpose of this repository is to strengthen my Java fundamentals through simple programs and practical examples.

## 📚 Concepts Covered

### 1. Class
- Understanding what a class is.
- Creating a class in Java.
- Defining variables and methods inside a class.

### 2. Object Creation
- Understanding what an object is.
- Creating objects using the `new` operator.
- Accessing class members through objects.

### 3. Constructor
- Understanding constructors in Java.
- Creating and using constructors.
- Initializing object properties through constructors.
- Understanding the role of constructors during object creation.

### 4. Constructor Overloading
- Defining multiple constructors in the same class.
- Using different parameter lists for constructors.
- Understanding how Java selects a constructor based on the arguments passed.

### 5. Wrapper Classes
- Understanding wrapper classes in Java.
- Learning the wrapper classes for primitive data types.
- Introduction to autoboxing and unboxing.

Examples of wrapper classes:
- `Integer`
- `Double`
- `Float`
- `Character`
- `Boolean`
- `Byte`
- `Short`
- `Long`

### 6. `new` Operator
- Understanding the `new` operator in Java.
- Creating objects dynamically.
- Learning how object creation invokes a constructor.

### 7. Passing an Object to Another Object
- Passing objects as arguments to methods or constructors.
- Accessing data from one object through another object's reference.
- Understanding object references and how Java passes arguments by value.

### 8. `final` Keyword
- Understanding the `final` keyword in Java.
- Using `final` with variables to prevent reassignment.
- Using `final` with methods to prevent overriding.
- Using `final` with classes to prevent inheritance.

**Note:** This repository covers the `final` keyword only, not the `finally` block or `finalize()` method.

## 🚀 How to Run the Programs

1. Install the Java Development Kit (JDK).
2. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

3. Navigate to the project directory:

   ```bash
   cd <your-project-directory>
   ```

4. Compile a Java program:

   ```bash
   javac Main.java
   ```

5. Run the compiled program:

   ```bash
   java Main
   ```

**Note:** Replace `Main.java` with the appropriate filename for the program you want to execute.
