# ☕ Java Object-Oriented Programming (OOP) – Part 1

## 📌 About This Repository

This repository contains my beginner-level learning journey in **Object-Oriented Programming (OOP) using Java**. I covered the fundamental concepts of classes, objects, constructors, constructor overloading, wrapper classes, the `new` operator, and passing objects as arguments to methods.

The goal is to build a strong foundation in Java OOP before moving on to advanced concepts.

## 📚 Concepts Covered

### 1. Class in Java
- A class is a blueprint for creating objects.
- It defines the properties (variables) and behaviors (methods) of objects.

### 2. Object Creation
- An object is an instance of a class.
- Objects are used to access instance variables and methods.
- Learned how to create and initialize objects in Java.

### 3. Constructors
- A constructor initializes an object when it is created.
- The constructor name must match the class name.
- Constructors do not have a return type.
- Learned how to create and use constructors.

### 4. Constructor Overloading
- Constructor overloading means defining multiple constructors in the same class with different parameter lists.
- It allows objects to be initialized in different ways.

### 5. Wrapper Classes
- Wrapper classes convert primitive values into corresponding object types.
- Examples:
  - `int` → `Integer`
  - `char` → `Character`
  - `double` → `Double`
  - `boolean` → `Boolean`
  - `float` → `Float`
  - `long` → `Long`
  - `short` → `Short`
  - `byte` → `Byte`

### 6. The `new` Operator
- The `new` operator creates objects of classes.
- It allocates memory for the object and invokes the appropriate constructor.

Example:

```java
Student s1 = new Student();
```

### 7. Passing Objects to Methods
- Learned how to pass an object as an argument to a method.
- A method can access the passed object's fields and methods.
- Java passes arguments by value, including object references.

## ▶️ How to Run the Programs

1. Install the Java Development Kit (JDK).
2. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

3. Navigate to the project directory.
4. Compile your Java file:

   ```bash
   javac Main.java
   ```

5. Run the compiled program:

   ```bash
   java Main
   ```

   Replace `Main.java` with the appropriate filename for your program.
